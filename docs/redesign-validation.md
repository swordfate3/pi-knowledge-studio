## 2. 固定测试集

先创建可公开再分发的合成 fixture，记录输入 hash、构建脚本、许可证和人工标注；不提交私有教材、真实密钥、运行数据库、模型缓存。

- 含文字、位图、矢量图、旋转/裁切与干扰图片的数字 PDF。
- 同一图片重复出现，图注不同；相同图放在两个不同来源。
- Markdown 正文不变只替换 sidecar 图片。
- 独立 PNG/JPEG/WebP，图中文字、视觉内容、无关图片。
- 第二波补扫描 PDF、DOCX 媒体和结构定位、静态 HTML 图文。
- 异常：不支持/加密/损坏、MIME 欺骗、超大像素、路径穿越、symlink、活动 HTML/SVG、archive bomb、重定向。

第一套问答标注至少60条，建议20条开发集、40条冻结验收集；覆盖精确标识符、同义表达、中文短词、中英混排、图注/正文关联、图片描述独有概念、无答案。按类型分别报告，不让大量简单文字题掩盖图像漏检。为每题标注可接受 evidence IDs/occurrence IDs，评审后冻结，禁止看结果后改正确答案。

## 3. 提议的首轮发布门槛

以下是**事前目标，不是实测成绩，也不外推所有文档**。如果失败，记录原因并修复；若改变目标，必须在新一轮未见过的验证集上预先登记。

| 指标 | 门槛 |
| --- | --- |
| 原字节保留 | 所有指定“可准确恢复”的 fixture 资源 SHA-256 一致率100% |
| 原图/派生分类 | 0个派生物被误标为字节原图 |
| 重复图定位 | 标注的 occurrence 全部保留，0个悬空引用 |
| 引用可解析 | 导出的 source/revision/locator/asset 全部解析成功 |
| 离线可携带 | 移走输出、断网、隐藏原数据根后，全部预期图片显示；0个内部绝对路径依赖 |
| 更新/删除 | 重试幂等；侧边图片变化触发修订；删后查询及延迟作业0次复活 |
| 快照一致性 | 并发更新/重建乱序完成不覆盖新快照；查询中切换模型仍使用固定快照及其 query embedding 配置 |
| 离线证据 | 获准的最小引用片段随 evidence.json 导出，隐藏源文件后仍可检查；provenance-only 明确不满足此门槛 |
| 向量隔离 | 同维不同模型/版本/任务前缀的向量拒绝混用；错误维度/NaN/数量错显式失败 |
| 安全负例 | 0次越界读取、活动脚本执行、未批准出站；恶意解析有界终止 |
| 文字与图文 evidence Recall@10 | 宏平均目标≥0.90，按题型单独报告分子/分母 |
| 相关图片 Recall@5 | 有 gold 图片问题的宏平均目标≥0.90；干扰图错误选用单独报告 |
| 生成语义 | 小规模人工复核发布样例中0条无证据事实，0张不支持邻近说明的图片 |
| 无答案问题 | 全部明确缺证据，不伪造引用或拿无关图片补齐 |

记录 nDCG@10、Recall@20、延迟 p50/p95、索引/资产体积、解析覆盖率、调用量和重试量。性能门槛在 P1 确认文档规模、硬件及并发后冻结；目前不承诺任意规模的毫秒级搜索。小样本门槛只作回归，不声称统计显著性。

## 4. 检索消融实验

同一语料、同一冻结问题集、同一解析快照；检索评测不混入生成模型的变化。

1. 旧 substring vs 中文 BM25：测升级价值及短词/标识符表现。
2. BM25 vs dense vs 双路 RRF：特别检查 BM25 无命中但语义正确的案例。
3. RRF vs RRF+reranker：质量增益与时间/费用。
4. 图文关系扩展开/关：无关键词文件名的原图能否被正确找回。
5. OCR/视觉描述开/关：新增召回是否引入错误解释；原文与描述分开。
6. WeMM 维度候选：先512与1024，必要时再256/2560；缓存、预算、索引隔离固定。
7. 确有视觉漏检后，再比较直接图文 embedding 或页面多向量检索。

调参仅使用开发集；保留逐题失败样例。不同 reranker 成绩不能与不同生成提示混在一起解释。

## 5. 远程验证计划（尚未执行）

用户已授权必要的远程验证/下载；以下只规划，不操作服务。

- 先读最新 registry，分层查 SSH、远程健康、模型 ID、端口/PID、本地隧道、GPU；健康现有服务优先复用。
- 第一轮仅合成内容，建议预算：embedding 请求≤20次（含重试）、生成/视觉请求合计≤10次，每次最多1张≤1MiB测试图，整轮≤10分钟。运行前明确打印实际计划，可调整后记录。批大小另受模型限制。
- WeMM 检查 model identity、明确维度、批量、归一化声明与实际向量、有限值及失败行为；重复性以容差比较，不苛求 GPU 浮点字节一致。
- Qwen 先确认实际 API schema 与文字生成；视觉只有在服务声明和实际图片请求验证后才变成 verified。
- 生产服务不做过载/恶意请求压力测试；错误、超限、429、超时在 mock/隔离测试服务验证。
- 缺少能力时先核验候选模型官方卡片、许可证、Windows/运行时兼容性、磁盘、依赖；注册 launch/health/ports/GPU/资源需求后，再做新鲜资源门禁。
- 不根据旧显存快照启动，不停止未明确点名并确认的服务，不自动切换其他供应商接收数据。
- 本轮未访问远程、未推理、未下载或启停模型；后续每次操作需独立记录结果。

## 6. 非破坏迁移与回退

v1 collection 只读，导入新数据根；保留 legacy IDs 映射。旧 source/asset 路径是未信任数据，不是读任意文件或抓取 URL 的授权：先展示迁移范围，批准 source roots 后按正常路径/MIME/配额规则读取；禁止自动网络抓取和远程推理。可验证的资产逐一核验 hash；缺失或不可验证的资产隔离/标记 unknown，源文档不可用或定位缺失也标记 unknown，不以同文档归属虚构图文关联。增加恶意 legacy 路径、迁移中断与幂等重试测试。

重新解析可用原文件后构建新 generation。比对记录数、资产、引用和检索 fixture，再显式切换。先保留旧库与旧索引，清理另行确认。绝不拿已安装的 FreeRTOS KB 初始化内部引擎或试迁移。
