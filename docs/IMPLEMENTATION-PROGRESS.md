The first bounded local end-to-end implementation is available. It is not the full broad-format production design. PDF pictures are decoded bitmaps associated by page, not guaranteed original bytes or complete figure extraction. Original PNG/JPEG/WebP bytes are preserved for standalone and supported Markdown/DOCX/HTML images. JPEG/WebP display renditions ignore EXIF orientation and are decoder-recipe-bound; original metadata remains in exported originals. Model references are structurally validated, not proof that every generated claim is true.
