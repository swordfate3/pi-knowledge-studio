⑤ 接下来怎样才算交付，而不是又做一小块？

1先跑通真正的 Pi 完整操作，不只证明工具能加载。
2用真实视觉／重排服务验证已写好的接口。
3解决 OCR 依赖，让扫描件也能入库。
4用未参与开发的资料出题，检查找得准不准、图对不对。
5补齐长期使用所需的稳定性，再做整体交付验收。

OCR 卡住，不代表其他工作都不能继续。不能再把“一个模块通过测试”当成“整个项目完成”。
